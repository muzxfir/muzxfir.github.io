# Custom README Update

The website no longer displays the original repository README.

## How it works

For every repository, create a Markdown file inside:

`project-content/`

The file name must exactly match the repository name.

Examples:

- Repository: `Auto-Filter-v7`
- File: `project-content/Auto-Filter-v7.md`

- Repository: `MovieVault-v2`
- File: `project-content/MovieVault-v2.md`

If a matching file does not exist, the website displays:

`project-content/default.md`

## Upload

Upload or replace:

- `project.js`
- `project-content/` folder

You may also upload the other included files if they are not already present.
